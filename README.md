# Ngwa Nforbi Law Firm

Official website of Ngwa Nforbi Law Firm. Placeholder copy (Lorem Ipsum) and a Grassfields / Bafut chieftaincy visual direction, ready to deploy on Vercel.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy on Vercel

1. Push this repository to GitHub.
2. Import the project in [Vercel](https://vercel.com/new).
3. Framework preset: **Next.js**. Build command `next build`, output as detected.
4. Deploy. No environment variables are required for this placeholder site.
